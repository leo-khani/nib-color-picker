# Security Policy

Security reports should not be filed as public issues. Use GitHub's private vulnerability
reporting feature for this repository. Include the affected version, reproduction steps,
impact, and any suggested mitigation.

The maintainers will acknowledge a report within seven days, investigate it privately,
and coordinate disclosure after a fix is available. Supported releases are the latest
minor release on the default branch.

Nib works offline and does not intentionally transmit screen content or color history.
Reports involving unexpected network access, arbitrary command execution, unsafe import
handling, or excessive Tauri permissions are treated as high priority.
